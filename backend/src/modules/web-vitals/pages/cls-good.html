Learn web performance

Try reading this paragraph while the page loads. Same image, same banner, same timing, but nothing moves. The space was already reserved.

Layout shift score = impact fraction (how much of the viewport moved) × distance fraction (how far it moved). Large elements moving far = large score.

What changed?
  1. width="960" height="480" on the image. CSS height: auto keeps it responsive, and the browser uses the ratio to reserve the space.
  2. The banner slot has a min-height, shown striped while it's empty. For real ads, reserve the most common size, or place them below the fold.
