Learn web performance

Try reading this paragraph while the page loads. It moves twice: once when the image arrives (0.8s) and again when the promo banner is injected at the top (1.5s). If you were about to tap a link, you'd tap the wrong thing.

Layout shift score = impact fraction (how much of the viewport moved) × distance fraction (how far it moved). Large elements moving far = large score.

Why is CLS high here?
  1. The image has no width/height, so its box height is 0 until it loads.
  2. The banner is injected above existing content with no reserved space.
