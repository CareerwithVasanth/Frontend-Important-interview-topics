Learn web performance

Why is LCP slow here? The hero image is the largest element, and three things delay it:
  1. A render-blocking <link rel="stylesheet"> in <head> (2s).
  2. Client-side rendering: the image URL only exists after JS runs and api/hero responds (1s). The browser's preload scanner can't discover it in the HTML.
  3. loading="lazy" on an above-the-fold image deprioritises it.
The image itself takes 1.2s on both pages. Only the frontend code is different.

Tip: don't click or scroll until the image appears. User input stops LCP measurement.
