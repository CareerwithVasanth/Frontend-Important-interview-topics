1 · Iframes

Each team ships a whole page, and the shell puts it in an <iframe>. Each iframe is a separate document with its own JS realm, DOM, CSS and (because it's a different origin) its own localStorage.

  • Communication: postMessage only. Products → shell → Cart. Every receiver must check event.origin.
  • Props: the initial currency is in the iframe URL (?currency=INR), and later changes are sent with postMessage.
  • Layout: the shell can't see the content height, so each iframe reports it with a resize message.
  • Failure: the shell can't read an iframe's HTTP status. It waits for a ready handshake and shows a fallback after a timeout.
  • Cost: in the Network tab, every iframe downloads its own document, scripts and styles. Nothing is shared.
